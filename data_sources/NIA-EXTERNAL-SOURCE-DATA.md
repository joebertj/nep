# NIA source archives

The large NIA source folders used by `build_nia_source_sections.py` are stored outside this repository at:

`/Volumes/T5 EVO/nep/data_sources/`

The five folders retain their original names. On another machine, set `NEP_NIA_SOURCE_ROOT` to the directory containing those five folders before running the NIA builder. The project workbook and PSGC location index remain in this repository under `data_sources/`.
