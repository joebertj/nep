How these counts are computed

The denominator is all HGAB project rows. Proposal documents link directly by title or through a selected NEP–HGAB counterpart. Senate PDFs link by exact or accepted relaxed first-page title, or by a file in a uniquely resolved HGAB code. Ambiguous code links are left unassigned. Each source and document type deduplicates by House row ID; source counts and categories can overlap. Signatory names are document-extracted candidates, not verified identities or a current officeholder roster. Photo pages and embedded coordinates are not content-verified. A row without a match is not proof that no document exists.
